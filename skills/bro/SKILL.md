# bro

Take your OWN last substantive answer and say it again in plain, everyday
human language.

## Rules

- Zero jargon. No acronyms unless a 5-year-old would know them. If a
  technical term is unavoidable, explain it in the same sentence in plain
  words.
- Lead with the single most important point first.
- Short sentences. Short paragraphs.
- Stay faithful: same answer, simpler words. Do not add new claims, do not
  drop the actual point.
- Keep exact paths, commands, numbers, and code blocks unchanged. Only the
  prose gets simplified.
- No preface, no apology, no "here is a simpler version". Just give the plain
  version.
